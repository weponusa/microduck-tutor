五个脚本

表格法 → 手写 REINFORCE → 环境封装 → PPO 训练 → 评估。都在 rl-lab/ 里，纯 CPU 就能跑完。

rl-lab/*.py · 见 README

它是怎么练出来的

从模型文件到在网页里站立，四步，每步都是真的。

STEP 01

模型

官方 MJCF 模型：16 段骨骼、38 块 3D 打印零件、14 个位置型关节。头重脚轻是它站不稳的根本原因。

assets/mjcf/microduck/
STEP 02

封装成环境

把模型包成「观测 36 个数 / 动作 14 个关节 / 奖励 = 活着 + 站直 − 乱动」的环境，每 0.02 秒决策一次。

rl-lab/03_microduck_env.py
STEP 03

PPO 训练

50 万步、3 分钟、纯 CPU。前 1650 个回合一直趴在 40 步，之后 1300 个回合冲到满分。

rl-lab/04_train_duck.py
STEP 04

搬到网页

把训练好的策略权重导成 JSON，用 MuJoCo 的 WebAssembly 版在浏览器里跑真物理、真策略。

duck_policy.json · course.html

几个数字

都是这个项目里实测出来的。

40 步关掉策略能撑多久（0.8 秒）
500 步训练后满分（10 秒不倒）
1650曲线开始抬头的回合（真实拐点）
10³⁶36 个数字切 10 档后的表格行数

怎么自己跑

全本地，不联网，不用装 Python 包也能看网页。

# 启动本地服务（所有页面都从这儿进） ./run.sh # 或者只跑脚本 cd rl-lab python3 01_gridworld_qlearning.py # 格子世界，不需要任何库 .venv/bin/python 02_cartpole_pg.py # 手写神经网络，25 秒 .venv/bin/python 03_microduck_env.py # 把鸭子接成环境，3 秒 .venv/bin/python 04_train_duck.py --steps 500000 # PPO 训练，约 3 分钟 .venv/bin/python 05_eval_duck.py # 考试，10 秒
来源与许可。 机器人模型来自 Pollen Robotics 的 MicroDuck 开源项目（Apache-2.0），物理用 Google DeepMind 的 MuJoCo（WASM 官方绑定，Apache-2.0），渲染用 three.js（MIT）。 策略权重是本仓库训练出来的，存放在 rl-lab/runs/duck_policy.json。全部内容在本机运行，不上传任何数据。
